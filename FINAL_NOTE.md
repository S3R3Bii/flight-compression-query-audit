# Final aircraft retain the same conservative conclusion

The 34 source, method, checker, fixture and development dependencies were committed in revision 324649f9bdbbbb7581e9fabd10036665f163dd4a before any final-aircraft compression/query score. The development selector chose identity. Its application to 65 runs from 17 different aircraft retains all point records and has zero reference/query error by construction. No new configuration was selected from the final results.

All eleven predeclared final comparisons remain visible. Geometric 25 m retains 8.0634% of the identity point-record bytes but fails at least one fixed budget in all 65 runs. Its maximum time-aligned position error is 1,038.37 m, maximum zone-occupancy error is 59 seconds, and maximum defined first-transition error is 51 seconds. The geometric tolerance measures distance to a chord, not position at the same time.

Time-synchronous 10 m retains 33.0323% of point-record bytes and meets the 25 m position and both timing requirements on every final run. It still fails the 1% horizontal route-length budget on twelve runs. A small position error does not by itself establish the fidelity of a cumulative path-length query. Smaller tolerances, a different application budget or a write-time query check require a separately defined follow-up; none was selected from this final comparison.

Independent final verification passes 2,680,129 conditions across 715 run/configuration cases. It checks 329,307 actual private point diagnostics and 1,353,861 split-interior evaluations, decodes retained binary records separately, reconstructs positions and queries with Decimal, recomputes equal-aircraft summaries with SQLite and preserves every failure. The recorded source archive and private input hash are unchanged. Counts, timestamps, indices, query states, guard decisions and the selected configuration require exact agreement; floating numerical fields use the declared tolerances.

These are results for processed, filtered and cubic-interpolated source tracks. The horizontal route-length rule preserves fluctuations in that processed reference, which are not established as true aircraft motion. Its operational suitability has not been calibrated. The 24-scene slice is a convenience sample from one airport's weekly archive; aircraft and runs share airport, weather, day and processing conditions. Runs are not asserted to be complete independent flights. The byte metric is the declared 32-byte point-record format with an eight-byte header, not a ZIP/database/cloud bill. No actual airline delay, operational safety, physical sensor accuracy, deployment, adoption, saving or new compression algorithm is established.

The practical recommendation is limited and testable: define the queries and error budgets before discarding original points. Under this study's budgets, the tested grid does not justify replacing the original records with one smaller global configuration. All source coordinates, original aircraft identifiers and diagnostic payloads remain private. Figures, manuscript, full-history replays and exact remote release checks are still required before this becomes a completed program release.
