# Environment and replay contract

The measured analysis used CPython 3.10.11 and NumPy 2.2.5. An independent full-history CPython 3.12.14 clone used the same NumPy version. Exact analysis revision and runtime receipts are in data/replay_validation.json. Figures use Matplotlib 3.10.9 and DejaVu Sans. The PDF was compiled with Tectonic and rendered with Poppler at 95 dpi; CI checks the reviewed artifacts without requiring TeX. pypdf 6.10.0 reads its values and page structure.

Run src/replay.py from a full-history clone with a separately downloaded exact archive and fresh work and receipt paths. Network acquisition is a distinct prior step. The analysis checks all 34 frozen dependency hashes before final execution. Source and working input hashes are bound independently. Full reconstruction keeps recorded coordinates outside Git; ignore paths are not permission to publish them.

Counts, source members, source/payload identities, retained indices, query seconds and states, guard outcomes, and selected setting must match exactly. Recomputed floating values allow absolute differences of 1e-8 m for coordinates/reconstruction/error distances, 1e-6 square metres for MSE, 1e-6 m for accumulated route length and 1e-10 for ratios. These tolerances were frozen before final scores. Numeric values near strict source-query boundaries are independently resolved with Decimal rather than rounded into a pass. Two as-run diagnostic hash fields and the artifact hashes inside their independent verification receipts are regenerated and checked against the current private bytes; underlying decoded values still obey the exact/tolerant policy. This is not universal byte equality across runtimes.

The point representation is an 8-byte count plus 32 bytes per retained point: little-endian signed int64 elapsed seconds and three float64 metre coordinates. It is not the source ZIP/CSV encoding. There is no learned estimator, hyperparameter tuning or production performance benchmark. The fixed reducer grid and authored fidelity budgets are choices, not empirically validated operational requirements. Equal-aircraft summaries first average run-level metrics within each aircraft; the mean of run RMSEs is not the square root of mean run MSE.

To regenerate figures separately install requirements-figures.txt and run src/make_figures.py followed by src/verify_figures.py. Do not overwrite a reviewed paper figure without regenerating the scoped manuscript receipt and inspecting its current renders. A successful static paper check alone does not establish that new renders were visually reviewed.
